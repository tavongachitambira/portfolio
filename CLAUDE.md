## Gotchas
- Cache Components is on: no `new Date()`/`Math.random()` in prerendered code; IO (reading files) needs `"use cache"` + `cacheLife` to stay static; route files may only export HTTP verbs and config (put shared constants in `lib/`); dynamic routes need `generateStaticParams` with at least one entry, and should read `params` inside `<Suspense>`.
- Pages you navigate away from stay mounted but hidden, so an id such as `#connect` can exist twice. Look elements up through `visibleById` (see `CommandPalette`), not `getElementById`.
- Ask providers: model names and request fields come from the providers' docs (Gemini's OpenAI-compatible endpoint, xAI chat completions) and could not all be tried against the live APIs here. A wrong model name shows as `ask: upstream error. <provider> 404 …` in the server log (set `ASK_MODEL`). Gemini's free tier has small quotas and may use prompts for training; xAI lists no free API tier. Errors are logged as provider, status and a short code only.
- Radix Dialog only returns focus to a `Dialog.Trigger`; ours open from anywhere, hence `useReturnFocus`.
- Google Fonts are blocked in the sandbox and `NEXT_FONT_GOOGLE_MOCKED_RESPONSES` does not work with Turbopack. Build in a throwaway copy (`tar` the repo without `node_modules`/`.next`, then `cp -al node_modules`) with the `next/font/google` import and the two font consts in `app/layout.tsx` replaced by `{ variable: "", className: "" }`. For screenshots against `next dev`, inject `:root{--font-jakarta:Inter,sans-serif;--font-geist-mono:"DejaVu Sans Mono",monospace}`.
- Shell cwd resets: always `cd /home/claude/portfolio &&`. Don't `pkill -f "next dev"` (it matches the command itself); use `fuser -k 3000/tcp`. Restart the dev server after changing data modules if HMR goes stale. The dev server's in-memory rate limiter also needs a restart after a 429 test.
- react-hooks lint rejects reading refs through a hook's returned object (return callbacks and destructure) and setState called synchronously in an effect (start work from event handlers, as `useAsk` does).
- Pre-existing, not mine: 2 lint errors + 1 warning (SkillsPreview, SkillMeters, Plasma), the next-themes "script tag" dev warning, and a reduced-motion hydration mismatch in `components/layout/ambient.tsx` that was noted earlier (it did not reproduce in the last run).
- Git: single-branch clone; to get upstream tracking add `remote.origin.fetch +refs/heads/<branch>:refs/remotes/origin/<branch>` then fetch.
- Commits end with the `Co-Authored-By` / `Claude-Session` lines. Don't commit to `main`.
